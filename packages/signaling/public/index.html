      How this is private
      • Calls and chat travel encrypted, directly between the two devices. This server only introduces you.
      • Each call shows a six-digit code. Read it aloud: if both screens match, no one — not even this server — is in the middle.
      • Invitation links work once. Reloading during a call needs a new link.
      • Messages are saved only on your devices, unencrypted in this browser. Use disappearing messages or Burn for sensitive chats.
      • You still trust your devices and the server that delivers this app. On phones, use Add to Home Screen and keep the app open during conversations.
